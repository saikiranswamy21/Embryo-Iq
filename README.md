# 🧬 EmbryoIQ

### AI-Based Decision Support System for Embryo Selection in IVF

EmbryoIQ is an AI-based healthcare decision-support project designed to assist IVF professionals in analyzing embryo-related information and supporting embryo selection.

The project aims to bring embryo records, image analysis, embryo ranking, genetic risk assessment and IVF success prediction into a single platform.

---

## 🎯 Objectives

- Provide a centralized platform for embryo information management
- Analyze embryo images using AI and computer vision
- Support embryo quality assessment and ranking
- Assist with genetic risk prediction
- Predict IVF success using machine learning
- Provide doctors with an easy-to-use decision-support dashboard

---

## 🚀 Key Features

### 👨‍⚕️ Doctor Dashboard
Provides doctors with an overview of patients, cases and embryo records.

### 🧑‍🤝‍🧑 Patient Management
Stores and manages patient information and IVF case details.

### 🧬 Embryo Record Management
Maintains structured records of embryos associated with each IVF case.

### 🖼️ Embryo Image Analysis
Uses computer vision and deep learning techniques to analyze embryo images.

### 📊 Embryo Ranking
Analyzes embryo characteristics and provides a ranking to support clinical decision-making.

### 🧪 Genetic Risk Prediction
Uses machine learning approaches to estimate potential genetic risks from available data.

### 📈 IVF Success Prediction
Provides an AI-based prediction using relevant patient and embryo features.
